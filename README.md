E-Commerce Sales Dashboard
This project is an interactive sales dashboard designed to analyze and visualize key metrics from e-commerce sales data. It helps businesses track revenue trends, best-selling products, customer behavior, and regional performance to make informed decisions.

Features
Overview of total sales and revenue trends over time
Breakdown of sales by product categories and individual items
Identification of top customers and high-value regions
Interactive filters and slicers for dynamic data exploration
Key Performance Indicators (KPIs) displayed for quick insights
